# Link na bio — Marlon Felipe

Página estática responsiva pronta para GitHub e Vercel.

## Configurar os links

Edite o objeto `links` no início de `script.js` e substitua `#` pelas URLs do Plano Tração, Plano Presença/WhatsApp e Behance.

## Publicar pela Vercel

1. Crie um repositório no GitHub e envie estes arquivos.
2. Na Vercel, clique em **Add New → Project**.
3. Importe o repositório do GitHub.
4. Em **Framework Preset**, escolha **Other**.
5. Deixe **Build Command** vazio e use `.` como **Output Directory**.
6. Clique em **Deploy**.

Cada novo `git push` no branch principal atualizará o site automaticamente.
